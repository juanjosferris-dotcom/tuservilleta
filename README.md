## 🧩 Plugin TuServilleta - Configurador de Productos

Este repositorio incluye un plugin de WordPress para la personalización de servilletas, posavasos y manteles, diseñado para clientes de alto standing.

### Características del Plugin

- **Diseño elegante e intuitivo**: Sin colores chillones, ideal para clientes premium
- **6 pasos guiados**: Navegación estilo Tesla/Ryanair (clic en imagen para avanzar)
- **Filtrado inteligente**: Solo muestra opciones disponibles según el CSV importado
- **Integración de pagos**: PayPal y Stripe
- **Integración HubSpot**: Envío automático de leads
- **Panel de administración completo**: Configuración de pagos, imágenes y productos

### Instalación

1. Descarga el archivo `tuservilleta-plugin.zip` del repositorio
2. En WordPress, ve a **Plugins > Añadir nuevo > Subir plugin**
3. Selecciona el archivo ZIP y haz clic en **Instalar ahora**
4. Activa el plugin

### Configuración

1. **General**: Configura el nombre de la empresa y email de contacto
2. **Pagos**: Configura las credenciales de PayPal y/o Stripe
3. **Imágenes**: Sube las imágenes para cada opción de los pasos 1-4
4. **Productos (CSV)**: Importa tu catálogo de productos en formato CSV
5. **HubSpot**: Configura la integración con HubSpot CRM

### Formato del CSV

```
size;type;color;printing;quantity;price
Servilletas 20x20 (10x10 plegada);2 Capas;Blanco;Deluxe a 1 Tinta;250 uds.;45.50
```

### Shortcode

Usa el shortcode `[tuservilleta_configurador]` en cualquier página para mostrar el configurador.

### Opciones Disponibles

**Paso 1 - Tamaño (9 opciones)**:
- Servilletas 20x20, 24x24, 30x30, 33x33, 40x40 (2 variantes)
- Posavasos 9 cm (redondo y cuadrado)
- Mantelín 30x40 cm

**Paso 2 - Calidad (4 opciones)**: 2 Capas, 3 Capas, Doble Punto, Tisú Seco

**Paso 3 - Color (7 opciones)**: Blanco, Negro, Beige, Burdeos, Verde Pino, Azul Marino, Reciclado

**Paso 4 - Impresión (6 opciones)**: Deluxe 1/2 Tintas, Digital Todo Color, Sin Personalizar, Estándar 1/2 Tintas

**Paso 5 - Cantidad (8 opciones)**: 250 a 20.000 unidades

**Paso 6 - Presupuesto**: Resumen con precio sin IVA, IVA 21%, envío GRATIS y total

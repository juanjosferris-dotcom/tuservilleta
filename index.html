Guía rápida para subir imágenes estratégicas

Manual de uso
  1. Sube tus imágenes a /images/ (crear carpeta si no existe). Recomendado: hero 1600x900, producto pequeño 1200x1200, producto grande 1200x1200, detalle 1400x900.
  2. Actualiza las variables del bloque :root en la cabecera:
    --hero-image: url("images/hero.jpg");
    --small-image: url("images/servilleta-20.jpg");
    --large-image: url("images/servilleta-40.jpg");
    --detail-image: url("images/detail.jpg");
  3. Usa PNG/JPG optimizados (ideal < 400 KB cada uno). Ajusta nombres si difieren.
  4. Si necesitas otra imagen, duplica un bloque .media-block y define un nuevo background-image inline o añade una variable.
  5. Comprueba la previsualización en local con python -m http.server 8000 y abre http://localhost:8000.

Tip: las imágenes usan efecto hover sutil y overlay de texto para guiar al usuario sin saturar el contenido.
